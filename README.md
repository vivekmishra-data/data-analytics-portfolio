## 📊 Project 1: Executive Lending Analytics Dashboard

An end-to-end lending analytics dashboard for tracking loan portfolio 
performance, risk (DPD/NPA), collections, and cohort-level default trends.


### Features:
- KPI cards: Total Disbursed, Outstanding Balance, Default Rate, 
  Collection Efficiency
- DPD Aging & Risk Breakdown (On-Time / SMA buckets / NPA)
- Interactive bookmarks & toggle buttons (switch chart views)
- Cohort Vintage Analysis for default rate tracking
- Dynamic slicers: Partner, Employment Type, DPD Bucket



### Tools Used:
Power BI Desktop, DAX, Power Query, Data Modeling
